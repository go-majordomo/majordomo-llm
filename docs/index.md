% majordomo-llm

Unified Python interface for multiple LLM providers with cost tracking, retries, and structured outputs.

- Unified API over OpenAI, Anthropic, Gemini, DeepSeek, Cohere
- Automatic cost tracking and usage metrics
- Structured outputs via Pydantic models
- Optional async logging to DB + S3/local storage
- LLMCascade for automatic provider failover

Use Getting Started for installation and Quickstart. Explore Recipes for practical integrations.
